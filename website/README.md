# Meu Site

Uma estrutura completa de website com HTML5, CSS3 e JavaScript moderno.

## Estrutura do Projeto

```
website/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # JavaScript
└── README.md           # Documentação
```

## Como Usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Para desenvolvimento, use um servidor local (recomendado)

### Servidor Local Rápido

```bash
# Python 3
python -m http.server 8000

# Node.js (se tiver serve instalado)
npx serve

# PHP
php -S localhost:8000
```

## Personalização

### Cores
Modifique as variáveis CSS no arquivo `styles.css`:

```css
:root {
    --primary-color: #007bff;
    --secondary-color: #0056b3;
    --text-color: #333;
    --background-color: #fff;
}
```

### Conteúdo
Edite o arquivo `index.html` para alterar:
- Textos e conteúdo
- Seções
- Links e navegação
- Informações de contato

### Funcionalidades
Modifique `script.js` para adicionar:
- Novas interações
- Animações
- Integrações com APIs
- Validações customizadas
